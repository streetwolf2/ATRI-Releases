# ATRI downloads

This repository hosts ATRI installer downloads and public update metadata only. Application source is private and is not distributed here.

No new installer has been published yet. Use only an actual listed Release asset; the existence of this repository does not certify a build.

## Update channels

Stable releases and explicitly marked release candidates are separate. Updater-enabled versions will check the public signed release metadata without requiring access to the private source repository.

Checksums and public signatures accompany installers when available. Do not place access tokens, private keys, source snapshots, debug files, or personal configuration in issues or attachments.

## Privacy

No account credentials or user conversation data are stored in this repository. Installer programs necessarily contain executable code; public availability does not imply permission to obtain the private development repository.
